## Overview

Keyboard shortcuts allow me to perform common actions more quickly without always needing to use the mouse or navigate through menus. They can improve productivity when working with files, applications, and development tools.

## Useful Developer Shortcuts

### `⌘ + Space`

Opens Spotlight Search. I can quickly search for applications such as Terminal, Activity Monitor, Finder, or VS Code without navigating through folders.

### `⌘ + Tab`

Allows me to quickly switch between applications. This is useful when moving between my code editor, Terminal, browser, and other development tools.

### `⌘ + Shift + G`

In Finder, this opens the "Go to Folder" dialog. This is useful when I know the exact location of a project or file and want to navigate there quickly.

### `⌘ + Shift + 4`

Allows me to select a specific area of the screen for a screenshot. This is useful when documenting bugs or providing evidence for tasks.

### `Control + ⌘ + Q`

Immediately locks my Mac. This is useful for maintaining security when stepping away from my computer.
