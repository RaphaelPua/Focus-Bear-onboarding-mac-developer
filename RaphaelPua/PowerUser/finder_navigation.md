# Master Finder & File System Navigation

## Finder Tricks and Shortcuts

1. Open Finder

- Shortcut: Command (⌘) + Space, then type Finder
- Finder can also be opened by clicking the Finder icon in the Dock.

2. Open a new Finder window

- Shortcut: Command (⌘) + N
- This creates a new Finder window, which is useful when working between multiple folders.

3. Open a new Finder tab

- Shortcut: Command (⌘) + T
- Finder tabs allow multiple locations to be open in the same Finder window.

4. Close a Finder window

- Shortcut: Command (⌘) + W
- This closes the current Finder window without closing Finder completely.

5. Go to the Home folder

- Shortcut: Command (⌘) + Shift + H
- This takes me directly to my user home folder, where folders such as Documents, Downloads, Desktop, and Pictures are located.

6. Go to the Downloads folder

- Shortcut: Option (⌥) + Command (⌘) + L
- This opens the Downloads folder quickly.

7. Go to the Applications folder

- Shortcut: Shift + Command (⌘) + A
- This opens the Applications folder.

8. Go to a specific folder

- Shortcut: Shift + Command (⌘) + G
- This opens the "Go to Folder" window. I can enter a path such as:
~/Documents
or:
~/Downloads
This is useful when I already know the location of a file or folder.

9. Search for files

- Shortcut: Command (⌘) + F
- This opens Finder search. I can search for a file by its name, type, date, or other attributes.

10. Show hidden files

- Shortcut: Command (⌘) + Shift + .
- This toggles hidden files on and off.
- Hidden files are normally not displayed because they often contain system or configuration files. Showing them can be useful when working with development tools or configuration files.

11. Preview a file

- Shortcut: Select a file and press Space
- This opens Quick Look, allowing me to preview many files without opening the associated application.

12. Get information about a file

- Shortcut: Command (⌘) + I
- This opens the information panel for a file or folder. It can show information such as its size, location, permissions, and creation/modification dates.

13. Rename a file

- Shortcut: Select the file and press Return
- This allows the selected file or folder to be renamed.

14. Move a file to the Trash

- Shortcut: Command (⌘) + Delete
- This moves the selected file or folder to the Trash.

15. Create a new folder

- Shortcut: Shift + Command (⌘) + N
- This creates a new folder in the current Finder location.

16. Go back to the previous folder

- Shortcut: Command (⌘) + [
- This navigates back to the previous location.

17. Go forward to the next folder

- Shortcut: Command (⌘) + ]
- This moves forward after navigating backwards.

18. Open the Recent folder

- Shortcut: Option (⌥) + Command (⌘) + F
- The Recent folder provides quick access to recently used files.

19. Use Finder tags

- Finder allows files and folders to be given coloured tags and custom names. Tags can be used to organise files based on projects, priority, or other categories without moving the files into different folders.
- For example, I could create tags such as: University, Work, Important, and To Review.

20. Search using filters

- Finder search can be narrowed down using filters such as file type, modification date, and other attributes. This is useful when I know something about a file but don't remember its exact name or location.
- For example, I can search for -> kind:pdf: to find PDF files.
