# HomeBrew Packages

1. wget

- wget is a command-line utility used to download files from the internet. It can be useful when downloading files or resources directly from Terminal.

2. tree

- tree displays files and directories in a tree-like structure.
- This is useful for quickly understanding the structure of a software project.
- Ex: tree

3. jq

- jq is a command-line tool for processing and filtering JSON data. It can be useful when working with APIs and JSON responses during development.

4. htop

- htop provides an interactive view of running processes and system resource usage. It can help me understand how much CPU and memory different processes are using.

5. ripgrep

- ripgrep is a fast command-line search tool that can search through files and directories.
- It can be useful for finding specific text within a large codebase.
- Ex: rg "functionName"
